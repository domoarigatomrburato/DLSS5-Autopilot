# Invidia Claritatis for NVIDIA RTX

A Windows tool that sets up NVIDIA's DLSS 5 neural rendering in your games,
checks that it works, and keeps every game's DLSS files current.

**Status: being rewritten from scratch in C# with Avalonia.** Nothing here is
usable yet. The plan is in [docs/plans/rewrite.md](docs/plans/rewrite.md).

This project began as a fork of
[Kizzuwatnaa/DLSS5-Autopilot](https://github.com/Kizzuwatnaa/DLSS5-Autopilot),
whose Python app works today. That app, as it stood when the rewrite began,
is the tag `python-reference`: the rewrite takes what it does, not how.
